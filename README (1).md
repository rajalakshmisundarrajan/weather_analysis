# 🌦️ Weather Data Analysis Project

## 📌 Project Overview
This project performs an end-to-end data analysis pipeline on weather data using Python.  
It includes data loading, cleaning, statistical analysis, and visualization to extract meaningful insights.

## 🎯 Objectives
- Build a complete data analysis workflow
- Perform data cleaning and validation
- Generate statistical summaries
- Create visual representations of data
- Extract actionable insights

## 🛠️ Tech Stack
- Python
- Pandas
- Matplotlib
- NumPy (optional)

## ⚙️ Setup Instructions

### Install Dependencies
pip install -r requirements.txt

### Run the Project
python main.py

## 📊 Features
- Data Cleaning
- Statistical Analysis
- Line Chart Visualization
- Histogram Visualization

## 🔍 Key Insights
- Seasonal temperature variation observed
- Majority of values lie in moderate range
- Dataset is consistent with minimal anomalies
